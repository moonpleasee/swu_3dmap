## 2026-09-26 估算外观配置说明

本批没有把未确认楼栋的网络照片混用为本栋证据。184栋 `basis: inferred` 配置仅使用本栋 OSM 对象的 ID、原始多边形、中心点、最近道路、用途标签和已有层高，分别调整窗格密度、墙色、屋面收边、阳台/百叶和入口比例；这些是交互模型的明确估算，后续找到本栋照片后应逐栋替换并记录照片日期与可见范围。116栋已有照片或园区参考的外观字段保持原值。
